# Pitch Checker

Агент для Claude Desktop, который проверяет студенческие работы: питчи, гипотезы, ответы, учебные тексты и задания с ключом. Он находит ошибки, подтверждает их источниками и предлагает, как исправить.

## Как добавить агента

**1. Скачайте агента.**
Нажмите зелёную кнопку **Code → Download ZIP** вверху этой страницы и распакуйте архив.

**2. Установите Python** (если его ещё нет).
- Windows: скачайте с [python.org](https://www.python.org/downloads/). При установке поставьте галочку **«Add python.exe to PATH»**.
- Mac: скачайте с [python.org](https://www.python.org/downloads/). После установки откройте **Программы → Python 3.x** и один раз запустите **Install Certificates.command**.

**3. Запустите установку.**
- **Windows:** в распакованной папке нажмите правой кнопкой на `install.ps1` → **«Выполнить с помощью PowerShell»**.
- **Mac:** откройте **Терминал**, напечатайте `bash ` (с пробелом в конце), перетащите в окно файл `install.sh` и нажмите Enter.

В конце появится надпись **«Готово»**.

**4. Перезапустите Claude Desktop** и откройте вкладку **Code**.

## Как пользоваться

Во вкладке **Code** пришлите работу текстом или файлом (pptx, docx, pdf) и напишите, например:
- «проверь питч»
- «разбери ответ студента»
- «проверь задание и ключ»

Агент пришлёт отчёт: что неверно, почему, по какому источнику и как исправить. Если Claude спросит разрешение на поиск в интернете или запуск скриптов, разрешите.

## Если установка не сработала

Скопируйте файлы вручную:

| Что скопировать | Windows | Mac |
|---|---|---|
| Папку `skills/pitch-checker` | в `C:\Users\<ваше имя>\.claude\skills\` | в `~/.claude/skills/` |
| Оба файла из папки `agents` | в `C:\Users\<ваше имя>\.claude\agents\` | в `~/.claude/agents/` |

Если папок `skills` или `agents` нет, создайте их. На Mac папка `.claude` скрыта, в Finder её показывает **Cmd + Shift + .** (точка).

## Обновление

Скачайте новую версию и снова запустите установку. Прежняя версия сохранится рядом с пометкой `backup`.
