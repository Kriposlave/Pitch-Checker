# Журнал проверок

Одна запись на проверку. Нужен, чтобы видеть систематические ошибки агента и уточнять инструкции на данных.

Формат:

```
## <дата> — <название работы>
- Режим: питч / учебный текст / ответ студента / задание с ключом
- Итог: <1 строка>
- Перепроверка: субагент / самопроверка, кругов: N
- Источники, которые не открылись: …
- Ошибки агента, найденные перепроверкой или преподавателем: …
- Правка инструкций, если нужна: …
```
