# База проверенных фактов: бизнес, экономика, рынки

Перед поиском в интернете ищи здесь (Grep по ключевым словам). Для рыночных цифр обязательно смотри дату: если данным больше 2 лет, перепроверь их заново.

Правила и формат записи — как в `istoriya.md`, плюс поле «Год данных».

```
### <короткое название факта>
- Ключевые слова: …
- Факт: …
- Год данных: …
- Вердикт для типичной формулировки: …
- Цитата: «…» — <источник>, <тип>, <URL>
- Проверено: <дата>
```
