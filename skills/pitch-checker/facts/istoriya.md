# База проверенных фактов: история

Перед поиском в интернете ищи здесь (Grep по ключевым словам: имя, событие, год). Если факт найден и подходит к утверждению, используй запись: вердикт, цитату и ссылку. Повторно в интернете не проверяй.

Правила записи:
- Добавлять только факты, подтверждённые **дословными** цитатами из прочитанных источников.
- Одна запись — один факт. Ключевые слова — для поиска.
- Если факт позже оказался неточным, исправь запись и отметь дату исправления.

Формат:
```
### <короткое название факта>
- Ключевые слова: …
- Факт: …
- Вердикт для типичной формулировки: …
- Цитата: «…» — <источник>, <тип>, <URL>
- Проверено: <дата>
```
