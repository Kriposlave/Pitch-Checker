# Контрольные тесты

Тексты с закрытыми ключами. Нужны, чтобы **измерять**, становится ли агент точнее после каждой правки инструкций, а не верить на слово.

## Когда запускать
- После любой правки `fact-researcher.md`, `report-verifier.md`, `SKILL.md` или `lessons.md`.
- Раз в несколько недель, даже без правок: сайты меняются.

## Как запускать
1. Проверь `tekst.txt` теста по обычному порядку работы, но **без базы фактов**: в базе уже есть ответы на эти тесты, и с ней тест измерит только поиск по базе, а не качество исследования.
2. Исследователям и проверяющему файл `klyuch.md` **не передавай** и не открывай до готового отчёта.
3. После готового отчёта сравни вердикты с `klyuch.md` и заполни строку в таблице ниже.

## Метрики
- **Совпадение с ключом:** сколько утверждений из 8 получили ожидаемый вердикт.
- **Ложные ❌:** сколько раз «опровергнуто» поставлено без прямого противоречия. Цель — 0.
- **Доля A/B:** какая доля вердиктов по главным утверждениям опирается на источники уровня A или B. Цель — расти от прогона к прогону.
- **Дословные цитаты:** какая доля цитат из источников получена дословно, а не через пересказ.
- **Замечания проверяющего:** сколько важных и критичных замечаний. Цель — снижаться.
- **Время:** от начала до готового отчёта.

## Как сделать свой тест
1. Создайте папку `tests/test-N/`.
2. В `tekst.txt` — текст работы с несколькими заложенными ошибками (неверная дата, неверный автор, легенда, поданная как факт, ошибка в ключе задания).
3. В `klyuch.md` — ожидаемые вердикты, **составленные до проверки**. Агенту ключ не показывать.
4. **Не храните ключи там, где их увидят студенты.** Если папка skill доступна студентам, держите тесты отдельно.
