# Сайты, которые не открываются агентом

Не тратить на них время: сразу идти к запасному пути. Дополнять после каждой проверки.

| Сайт | Что происходит | Запасной путь |
|---|---|---|
| bigenc.ru, old.bigenc.ru (Большая российская энциклопедия) | HTTP 401 / тайм-аут SSL | Публичная архивная копия в Internet Archive: `https://web.archive.org/web/<дата>/<адрес статьи>` через `fetch_page.py`; перед сверкой цитат убрать мягкие переносы (U+00AD). В отчёте указывать ссылку на архивную копию. Если копии нет — фрагмент из поиска с пометкой |
| publishing.mpda.ru (журналы МДА, PDF) | Веб-чтение возвращает PDF без текста | Скачать PDF и извлечь текст локально (`scripts/extract_text.py` или skill pdf) |
